# 本机测试结果

日期：2026-10-28。本报告区分同机独立部署验收与未测试的其他电脑兼容性。

## 环境与实际入口

- Windows 本地桌面；PowerShell 7.6.5。
- 两套分别创建的 64 位 Python 3.14.2 venv，`include-system-site-packages = false`。
- SolidWorks COM 修订号 34.0.0（2026 系列），COM 注册、默认零件模板和默认装配体模板均检查成功。
- pywin32 312、mcp 1.30.0、Pillow 12.3.0、jsonschema 4.26.0。完整安装版本见 tested-dependencies.txt；它是实测快照，不是对所有平台的兼容承诺。
- 本机沙箱的临时目录写入和 DNS 曾阻止初始化；使用项目可写临时目录、经允许的联网安装后成功。沙箱访问 SolidWorks COM 返回拒绝访问，经审批的桌面进程访问通过。接收者的实际 Codex 权限仍需自行确认，项目不关闭沙箱或修改权限设置。

## ZIP 首次解压模拟

从候选 ZIP 解压到另一个全新目录，起始没有 .venv、没有本地 MCP 配置，没有读取原项目代码。实际运行 setup.ps1 -Mcp，重新创建 venv、安装依赖；配置中的解释器和服务脚本均解析到新解压目录。

在该环境重新执行 test_connection.py，并生成 **100×60×12 mm、中心 Ø8 mm 通孔板**，完成保存、关闭、重开、B-Rep 尺寸和体积检查及四视图输出；stdio MCP 再次通过真实调用。测试时核对新目录 src 与发布 src 逐字节一致。最终包只更新验收文档与清单，没有在首次解压测试后更改执行代码。

## 未验证的边界

- 没有第二台电脑、不同 Windows 用户/权限模型或另一 SolidWorks 安装的实测；不能宣称跨电脑兼容性已经通过。
- 没有替接收者登录 Codex，也没有验证另一用户的 Codex 桌面项目 MCP 发现及自然语言端到端流程。Python/stdio 接口实机通过与该项是两个不同结论。
- 除上述矩形通孔板和基本双组件装配外，94 个接口中的其他功能未经本轮实机验收。Mate、运动、复杂曲面、FeatureWorks、工程图、装配引用跨设备迁移不在本轮通过范围。
- 程序使用原执行层的选择、尺寸和特征方案；未证明所有草图完全定义，也未进行任意尺寸组合、故障恢复和模型缺陷反例的完整回归。
- 有效模板的相对路径/项目 JSON 覆盖、不同系统语言与多版本并存没有完成专项实测；无效相对路径的拒绝已测试。
- setup 的 Python 自动发现、显式 -Python 参数和 PowerShell 5.1 没有在全部安装组合上验证；本轮使用可用的 Python PATH 与 PowerShell 7.6.5。

详细能力边界见 CAPABILITIES.md。此包可以进行独立部署和具体建模验收，不代表任意机械需求无需检查即可交付。
