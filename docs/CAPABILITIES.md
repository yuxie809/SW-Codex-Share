# 能力和验收边界

验证日期：2026-10-28。此表针对本发布版本，不把“工具已注册”当作“功能已验证”。完整实际接口与参数见 TOOLS.json，也可以运行 sw.py --list / --schema。

| 功能 | 本轮状态 | 证据/限制 |
| --- | --- | --- |
| 连接 SolidWorks、读取运行版本和模板 | 已验证 | 64 位 Python 3.14.2、SolidWorks 34.0.0；无其他电脑实测 |
| 矩形草图、拉伸、圆草图、贯穿切除 | 已验证示例 | 80×50×10 mm 中心 Ø10 通孔板；首次解压环境另验 100×60×12 mm、Ø8 |
| 原生零件保存、关闭和重开 | 已验证 | 重建、单实体、尺寸、孔壁、体积、拉伸与切除特征检查通过 |
| STEP 导出 | 已验证写出 | 文件非空；本轮没有重导入 STEP 验收 |
| 标准四视图输出 | 已验证 | 板件及基本装配共八张图，已目视检查 |
| 基本装配体新建、插入两个组件 | 已验证示例 | 两个相同板件实例，保存重开、引用存在、无压缩、重建通过；不含 Mate |
| 自然语言参数化调用 | 可由 Codex 使用现有接口执行 | AGENTS.md + Python Runtime/CLI；本轮实际执行代码，未用另一个用户账号做自然语言端到端测试 |
| stdio MCP 入口 | 协议与 CAD 只读调用已验证 | 初始化、94工具发现、列表查询和错误返回；接收者桌面端加载仍需按教程确认 |
| 零件/装配体模板跨路径覆盖 | 自动发现和显式路径覆盖已验证 | 无效显式路径会报错；相对路径正常模板、项目 JSON 和不同系统语言/版本尚未实测 |
| 其他草图、旋转、扫描/放样、布尔、圆角、倒角、阵列、孔向导等 | 存在原有接口，本轮未验收 | 不作为自动交付保证；需具体任务实机检查 |
| Mate、装配干涉、配置、方程、特征编辑、FeatureWorks 识别 | 存在原有接口，本轮未验收 | 需要版本、许可、引用、自由度等专项验证 |
| 任意工程图理解/图纸到模型全流程 | 未包含 | sw-agent 图纸模块与采用历史未复制；此包为自然语言驱动的 CAD 执行层 |
| 自动工程图排版、钣金展开、运动/仿真、任意复杂曲面 | 未提供已验证工作流 | 不因 SolidWorks 产品具备能力而声称此包支持 |
| 无 SolidWorks、Linux/macOS/云容器内原生建模 | 不支持此部署路线 | 本包依赖 Windows 本机商业软件 COM |

原始项目的工程状态账、基础实机脚本和当前源代码已检查；本轮以独立发布包实测作为上述验收依据。当前全局 MCP 另有旧入口（工具名 sw_*），本发布版没有复制它的年份固定模板逻辑，也没有改动原入口配置。

所有长度参数默认毫米，工具内部转米；角度按各接口 Schema 使用度。直接 COM API 才用米/弧度。原始 API 多于表中验证范围，不应对外宣传为“任意零件自动建模全部支持”。
